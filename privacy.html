Privacy policy

Last updated: September 25, 2026

This assistant is used only by its owner, on the owner's own computer. It is not offered to anyone else.

Google user data

  • What is accessed: events on the owner's own Google Calendar (scope calendar.events), to read the day's commitments and to add or update the owner's planning blocks.
  • How it is used: only to plan the owner's day. It is not used for advertising, sold, or shared with anyone.
  • Where it is stored: on the owner's computer only. The sign-in token is encrypted with Windows data protection. No data is sent to any server operated for this assistant; none exists.
  • Removal: access can be revoked at any time from Google Account permissions, and deleting the local token removes all stored credentials.

This assistant's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
